# Bike-Sales-Dashboard
An end-to-end Excel data analysis project which involves data cleaning, standardization of data, pivot charts to visually represent the analyzed data in a dashboard.

## Key Insights
* **Income**: The data indicates that the person with the higher income correlated with the purchase of a bike in both male and female demographics.
* **Age Brackets**: The data indicates that Middle Aged(31-55) group purchased more bikes than any other age group.
* **Commute Distance**: The data indicates that higher the commute distance of a person the less likely he/she is likely to purchase a bike.

---
## Data Cleaning & Processing Steps
1. **Duplicates**: Removed duplicates in the data to maintain data integrity.
   
2. **Standardization**: Cleaned Column values to proper format (e.g.., Changed 'M'/'S' in Marital Status to 'Married'/'Single', Changed 'M'/'F' in Gender to 'Male'/'Female')
   
3. **Age Brackets**: Created a logic using nested ifs to create age brackets(i.e.., Adult, Middle Aged, Old)
